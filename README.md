# Automatisation des tests de Sauce Demo

> Étude de cas : conception et automatisation de tests fonctionnels end-to-end sur Sauce Demo, une application e-commerce de démonstration, avec Playwright et pytest.

## Versions du projet

- [`brouillon/`](brouillon/) : première itération de l'étude de cas
- [`brouillon_2/`](brouillon_2/) : deuxième itération
- [`saucedemo-playwright-tests/`](saucedemo-playwright-tests/) : version finale, à jour et utilisable
